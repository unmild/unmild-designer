01 / Mool · Code meets circuit

Write the response.
Watch the result.

A button press. A changing sensor input. An LED that follows your program. Mool connects supported C/Arduino-style code to the electrical behavior of ESP32 and STM32 models, so you can explore what your circuit does while you design it.

Start from a control example or write your own logic. Select the microcontroller, press Program and use Run to follow the response. Your programmed source and editor drafts stay with the board, ready for the next session.

React to the circuit
Read digital and analog inputs, drive GPIO and shape output with PWM.
Coordinate the behavior
Explore interrupts, supported timer callbacks and wired UART communication between parts.
Start with something useful
Try examples for temperature control, sensor processing, pulse handling and feedback control.

Run supported sketches in the workspace without installing an external compiler.

03 / Your first project

Start with an idea.
Leave with a build folder.

A straightforward path from opening Designer to finding your exported files.

  1. Open Designer. Create a project.

    Launch Unmild Designer and choose New project from the start screen.

  2. Give it a place to live.

    Select a folder, name your project and choose the board options. Click Create project.

  3. Build the idea. Review the board.

    Place and connect parts. Add Mool behavior where you need it, explore Live 3D and review the design checks.

  4. File → Export PCB package.

    Export the project, then open its folder. Your manufacturing and review files are in the build folder.

04 / Good to know

A few useful
answers.

What can I do in Unmild Designer?

Design PCB layouts, arrange multiple boards, write supported microcontroller programs in Mool, explore behavior in Live 3D, review design checks and export manufacturing files. It’s one desktop workspace for the board and what it does.

How does Mool work?

Mool runs a supported C/Arduino-style subset for ESP32 and STM32 models against the connected circuit. Choose a part, write or load an example and press Program. Programs and drafts are saved with the board. Running a sketch in Mool does not require an external compiler.

What does Live 3D show?

The board and its placed components in three dimensions, with live behavior for supported parts during Run. See LEDs respond, motors turn and controls affect the circuit while following readings and reported issues.

Can I use Designer offline?

Core design, local project saving, Mool and exports work on your computer without a Designer account or AI API key. Downloading the app, Store services, external links and contacting support use the internet.

Where are my projects and exports?

Your project lives in the folder you select. The editable board uses the .tamas format, and File → Export PCB package writes output to a build folder within the project. Keep the project folder backed up.

Can I change the workspace?

Yes. Customize colors, tool shortcuts, zoom and pan behavior, and arrange floating or docked panels. Designer saves your local preferences for the next session.

Where can I get it, and what does it cost?

Visit Unmild Designer on the Microsoft Store for current pricing, availability and installation details. For a product or purchase question, contact UNMILD.

How is Designer related to UNMILD?

Designer is UNMILD’s dedicated electronics design product. It has its own workspace and purpose, alongside the other tools at unmild.store.
